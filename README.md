# Promise, progress, and payoff examples

I wrote these two guides to show how the promise, progress, and payoff framework changes a technical how-to. Both cover the Strategy pattern in Python by exporting help articles as JSON or Markdown, using the same code.

The framework comes from Brandon Sanderson's creative writing lectures on plot, and I've adapted it for technical documentation. You can read the [official notes from the 2025 plot lecture](https://www.brandonsanderson.com/blogs/blog/brandon-sandersons-2025-guide-to-plot-lecture-2) to compare the original ideas with my version.

## Compare the two versions

1. Read the [before version](https://github.com/balapriyac/promise-progress-payoff-examples/blob/main/strategy_pattern_before.md), an explainer written without the framework.
2. Read the [after version](https://github.com/balapriyac/promise-progress-payoff-examples/blob/main/strategy_pattern_after.md), a step-by-step guide built with it.

As you compare them, look for who each page is for, how you can tell you're making progress, and how you know you've finished.
